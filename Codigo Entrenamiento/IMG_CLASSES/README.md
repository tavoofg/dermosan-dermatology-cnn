# 📂 Carpeta: IMG_CLASSES

En esta carpeta debe colocarse el **dataset de imágenes dermatológicas** utilizado para el entrenamiento del modelo.

- Dataset: *Skin Diseases Image Dataset*  
- Autor: Ismail Hossain (2021)  
- Fuente: [Kaggle](https://www.kaggle.com/datasets/ismailpromus/skin-diseases-image-dataset)  
- Contenido: 10 clases de enfermedades cutáneas  
- Total: 27,153 imágenes

> ⚠️ Esta carpeta no se incluye en el repositorio por su tamaño.
> El usuario debe descargar el dataset y extraerlo aquí antes de ejecutar el entrenamiento.
